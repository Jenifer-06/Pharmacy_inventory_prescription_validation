1.Title : 
     Pharmacy Inventory & Prescription Validation Platform 

2.Domain : 
     Healthcare management system 

         This project belongs to the Healthcare and Inventory Management domain. It helps pharmacies manage medicine stock, expiry dates, billing, and prescription verification through a web application.

3.Who is the user?
#Admin : 
Manage pharmacist accounts.
Add , update or remove medicines.
Manage suppliers.
#pharmacist:
Search and dispense medicines.
Upload and validate prescriptions.
Check expiry dates and stock availability.

4.What problem are we solving?
     Many pharmacies still use manual methods or basic software to manage medicines. This can lead to stock shortages, expired medicines, and billing errors. The proposed system automates these tasks and improves efficiency.

5.Proposed solution :
     As a solution to this problem I develop a web-based platform to manage inventory, validate prescriptions, monitor stock, and generate bills. The system will also provide alerts for low stock and expired medicines.

6.Core entities :
Users
Medicines
Suppliers
Inventory
Prescriptions
Sales

7.User roles and permissions :
    Admin: Manage users, medicines, suppliers, and reports.
    Pharmacist: Validate prescriptions, update inventory, and generate bills.

8.Success criteria :
Inventory is updated correctly.
Prescription validation works accurately.
Low-stock and expiry alerts are displayed.

9.Out of scope :
Online payments.
Home delivery.
Doctor booking appointment.

10.Chosen track :
    Backend: Java (Spring Boot)
    Frontend: React.js
    Database: MySQL
    Version Control: Git & GitHub
